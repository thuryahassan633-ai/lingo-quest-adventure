# Lingo Quest Adventure — النسخة المصممة لـ GitHub Pages

## ما الذي تغيّر؟
- تحديث بصري شامل للألوان والخلفيات والبطاقات لتصبح أقرب إلى أجواء مغامرة فضائية للأطفال، مع دعم الجوال والآيباد.
- الإبقاء على صفحات الألعاب: الحروف، الأرقام، تركيب الكلمات، المفردات، والأناشيد.
- إصلاح تسلسل نطق حروف الكلمة: تُضاف الحروف إلى طابور الصوت بدل إلغاء الحرف السابق عند بدء الحرف التالي.
- إضافة `.nojekyll` لتقليل تدخل Jekyll عند النشر من فرع.
- إبقاء مجلدي `data/` و`assets/` في موضعهما. مجلد `assets/` حاليًا لا يحتوي رسومات مرجعية فعلية؛ الأيقونات الزخرفية المستخدمة في الواجهة مبنية بالـ CSS والرموز التعبيرية.

## بنية الملفات
- `index.html` — شاشة البداية وزر Let's Play.
- `world.html` — اختيار عالم اللعبة.
- `letters.html` — لعبة الحروف.
- `numbers.html` — لعبة الأرقام.
- `builder.html` — تركيب الكلمات.
- `vocabulary.html` — المفردات والتهجئة.
- `songs.html` — أناشيد منطوقة عبر صوت المتصفح، وليست تسجيلات موسيقية أصلية.
- `style.css` — التصميم.
- `app.js` — التفاعلات والنطق والنجوم.
- `data/` — ملفات بيانات إضافية.
- `assets/` — مكان الصور والأصوات التي تضاف لاحقًا.

## الرفع على GitHub Pages من الآيباد
1. حمّلي ملف ZIP وافتحيه في تطبيق «الملفات» لفك الضغط.
2. افتحي المستودع الصحيح في GitHub من Safari.
3. قبل التغيير، احتفظي بنسخة من الملفات القديمة أو نزّلي ZIP للمستودع.
4. داخل المستودع، تأكدي من الفرع الذي ينشر الموقع غالبًا `main` ومن مجلد النشر في Settings → Pages. إذا كان المصدر `main` و`/(root)`، يجب أن يكون `index.html` في جذر المستودع مباشرة.
5. من تبويب Code اختاري Add file → Upload files. اختاري الملفات والمجلدات الموجودة داخل مجلد المشروع بعد فك الضغط، لا ملف ZIP وحده. ارفعي `index.html` وملفات HTML و`style.css` و`app.js` و`.nojekyll` ومجلدي `data` و`assets`.
6. إذا كان GitHub على متصفح الآيباد لا يسمح باختيار مجلد كامل، ارفعي الملفات من داخل كل مجلد على حدة مع الحفاظ على البنية. لا تضعي محتويات `data` أو `assets` في الجذر.
7. اكتبي رسالة مثل `Refresh Lingo Quest design` ثم اضغطي Commit changes.
8. افتحي Settings → Pages وتحققي أن Source مضبوط على Deploy from a branch، والفرع الصحيح و`/(root)` (إذا كان هذا هو إعداد مشروعك)، ثم Save إن غيّرتِ شيئًا.
9. افتحي Actions أو Settings → Pages وانتظري اكتمال النشر. افتحي Visit site. قد يستغرق ظهور التحديث عدة دقائق.
10. على الآيباد، إذا ظهر التصميم القديم، حدّثي الصفحة، ثم أغلقي تبويب الموقع وافتحيه مجددًا. يمكن أيضًا تجربة نافذة خاصة للتأكد من التخزين المؤقت.

## لتجنب رفع المجلدات بشكل خاطئ
البنية الصحيحة مثلًا:
```
index.html
style.css
app.js
world.html
letters.html
numbers.html
builder.html
vocabulary.html
songs.html
data/
  letters.json
  digraphs.json
assets/
.nojekyll
```
لا ترفعي مجلد المشروع الخارجي داخل المستودع بحيث يصبح المسار `lingo_quest_adventure_v3/index.html`، لأن GitHub Pages قد لا يجد `index.html` في جذر مصدر النشر.

## حذف النسخة القديمة بأمان
لا تحذفي المستودع القديم لمجرد أن الملفات تغيرت. إذا كان نفس المستودع سيستضيف النسخة الجديدة، ارفعي الملفات الجديدة فوق الملفات ذات الأسماء نفسها واحذفي فقط الملفات القديمة التي تأكدتِ أنها لم تعد مستخدمة. إذا أنشأتِ مستودعًا جديدًا، اختبري الرابط الجديد أولًا، ثم افتحي المستودع القديم → Settings → General → أسفل الصفحة Delete this repository. يتطلب الحذف كتابة اسم المستودع للتأكيد وهو إجراء قد يصعب التراجع عنه. حذف المستودع القديم قد يوقف رابط الموقع القديم.

## ملاحظات
- GitHub Pages يستضيف ملفات ثابتة فقط؛ لا توجد قاعدة بيانات أو خادم خلفي في هذا المشروع.
- الأصوات تعتمد على `SpeechSynthesis` المتاح في المتصفح؛ الأصوات تختلف حسب الجهاز واللغة المثبتة.
- هذا تحديث للتصميم الحالي وليس إعادة رسم مطابقة بالبكسل للصور المرجعية، ولا يتضمن حتى الآن ملفات رسومات أصلية لحيوانات أو تسجيلات موسيقية.
